# Multimodal Behavioural Biometrics for Augmented Reality

This repository contains the datasets and analysis code for the study:

**Multimodal Behavioural Biometrics for Cross-Session Identification and Open-Set Recognition in Augmented Reality**

The study investigates user identification from multimodal behavioural signals collected with Microsoft HoloLens 2, including:

- Eye-gaze behaviour
- Head movement
- Hand interaction

The dataset contains recordings from **55 participants** and includes evaluation of:

- Intrasession identification
- Cross-session identification
- Open-set recognition of non-enrolled users
